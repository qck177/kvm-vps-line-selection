## 美国KVM VPS，先看线路，再看配置

DMIT 当前官网把 Cloud Instance 定义为高性能 KVM 虚拟机，并在洛杉矶提供 Premium、Eyeball、Tier 1 三类网络。官方对三者的定位很明确：

* **Eyeball**：以 Tier 1 为基础，结合 CMI 等中国互联网运营商方向的路由，定位是价格与中国访问能力之间的折中。

所以，“美国 VPS”这个词本身信息量其实不够。

## DMIT 洛杉矶的三种网络，到底怎么选？

### Premium：为中国大陆访问付费

Premium 是最容易被搜索“美国KVM VPS”的人关注的一档，因为 DMIT 明确把 CN2 GIA 和中国大陆优化路由放进这一产品线。官方的描述重点是更少的跳数、更低的延迟和更低的丢包，目标就是中国大陆及亚太用户体验。

这类方案比较适合：

网站、API、面向中国大陆客户的 SaaS、跨境后台、需要频繁 SSH 管理的服务器，以及对国际链路稳定性比较敏感的业务。

对应的代价也很直接：**价格明显高于 Tier 1**。

### Eyeball：预算和中国访问之间的折中

Eyeball 的定位不是完全复刻 Premium，而是利用 CMI 等中国互联网运营商方向的网络资源做折中。官网明确写明，它不具备 Premium 那样的线路保证，但对于需要兼顾全球访问和中国居民网络的服务，可以作为成本更低的选择。

如果业务确实面向中国，但又不一定需要 Premium 级别的线路投入，这一层值得单独比较。

### Tier 1：不要为用不到的中国优化路线买单

Tier 1 的逻辑最简单：如果你的用户主要在美国、欧洲或其他海外地区，或者你的主要需求是普通计算、Docker、CI/CD、备份、测试、开发环境，那么它的网络定位已经很清楚。

DMIT 自己对 Tier 1 的描述就是面向亚太、北美和欧洲的通用高带宽网络，而不是中国大陆专线产品。

这也是当前 LAX 价格里非常明显的一条分界线。AS3 Tier 1 最低公开价只有 **$6.90/月**，而 Premium 的 AS3 TINY 则是 **$10.90/月**。

## 购买前，别只盯着“10Gbps”

这一点对备份、同步、对象存储代理、下载分发、视频资源、镜像同步一类任务尤其重要。
